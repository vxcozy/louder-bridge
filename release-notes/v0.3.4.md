# Louder Bridge 0.3.4

This prerelease fixes Hermes plugin recovery during setup, updates, and
uninstall.

## What changed

- Failed setup keeps the last complete managed plugin until Louder Bridge
  verifies the matching Hermes configuration.
- Rollback restores either the previous plugin or the new plugin. It does not
  remove both copies when a filesystem step fails.
- Uninstall asks Hermes to disable the plugin by name. It no longer removes a
  list entry by numeric index.
- Reinstall uses Hermes's normal enable command, which clears the disabled
  plugin entry.

Micro controls, voice input, Agent Key navigation, send, lighting, and terminal
behavior are unchanged.

smoke test and release checks also passed.

The Hermes tests use isolated profiles and cover install, update, uninstall,
concurrent configuration edits, and failed filesystem recovery.

Hermes Agent 0.19.0 still performs plugin disable as a separate read and write.
A different configuration write in that brief window can overwrite another
change. Hermes needs an atomic configuration operation to remove that final
race.

## Install

Download the Apple Silicon ZIP, move **Louder Bridge.app** to **Applications**,
and open it once. If macOS blocks it, open **System Settings > Privacy &
Security** and choose **Open Anyway**. Approve Input Monitoring and
Accessibility for Louder Bridge. Ghostty may also ask for Automation permission
the first time an Agent Key selects a terminal.

The GitHub build uses an ad hoc signature, so macOS may ask for permissions
again after an upgrade.

## Privacy

Louder Bridge runs locally. It collects no telemetry, audio, transcripts,
prompt content, project names, or session identifiers. Local diagnostics
require a private authentication token.

This remains a prerelease. Ghostty labels its AppleScript API as a preview, and
the device driver uses an independently documented protocol.
