# Louder Bridge 0.3.0

This prerelease adds Codex Micro support for local terminal agents in Ghostty.

## What works

- Run Claude Code, Codex CLI, or Hermes in Ghostty.
- See local session state on the six Agent Keys and exterior lighting.
- Press an Agent Key to focus its exact Ghostty window, tab, or split.
- Hold MIC to use macOS Dictation in the focused prompt, then release it to
  stop.
- Press the key beside MIC to send Return.

Ghostty only claims the Micro while a supported agent is attached to a real
terminal. Leaving Ghostty open at a shell prompt does not take the device away
from Codex Desktop or another supported app.

## What changed

Setup now adds lifecycle hooks to `~/.codex/hooks.json` without replacing
unrelated Codex hooks. Codex still makes its own trust decision and may ask you
to approve the Louder Bridge command on first use.

Terminal sessions share one Ghostty adapter. Session IDs are hashed before they
enter that store. The bridge uses Ghostty's stable terminal IDs for navigation,
a native Return key event for send, and the standard macOS Dictation command
for MIC.

## Compatibility

- Apple Silicon
- macOS 15 or newer
- Ghostty 1.3 or newer
- Local Claude Code, Codex CLI, or Hermes sessions
- Claude Desktop and Hermes Desktop remain supported

## Privacy

Louder Bridge runs locally. It collects no telemetry, audio, transcripts,
prompt content, project names, or session identifiers. Its local diagnostics
require a private authentication token.

## Download

The release contains an Apple Silicon ZIP, its SHA-256 checksum, and an SPDX
SBOM. The app uses an ad-hoc signature, so macOS may require **Open Anyway** in
**System Settings → Privacy & Security** on first launch.

Install **Louder Bridge.app** in **Applications**, open it once, and approve
Input Monitoring and Accessibility. Ghostty may ask separately for Automation
permission the first time Louder Bridge selects a terminal.

This is a prerelease. Ghostty labels its AppleScript API as a preview, and the
device driver still uses an independently documented protocol.
