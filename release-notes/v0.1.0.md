# Louder Bridge 0.1.0

This is a prerelease for testing Louder Bridge with the Work Louder Codex
Micro. It is not the stable v1 release.

Louder Bridge connects the Micro to local Claude Code sessions in Claude
Desktop. The six Agent Keys show session state and open the matching session.
Holding MIC starts voice input; releasing it stops. The key beside MIC sends
Return for submission and approval prompts.

For toggle-style composer buttons, Louder Bridge now clicks once on MIC press
and again on release. Press-and-hold buttons still use a continuous hold. The
Cowork composer route still needs physical release testing.

## Tested hardware

The development build passed a focused Bluetooth test on August 2, 2026:

- macOS 26.5.2
- Claude Desktop 1.24012.9
- Codex Micro firmware v0.4.1
- MIC hold and release in Claude Code
- dictated text inserted into the active composer
- one Return event from the send key
- running and complete lifecycle lighting

Codex was closed during the passing test. When both apps were open, the same
MIC input also reached Codex. Closing Codex removed that conflict.

USB-C, double-tap voice latching, the visible Cowork composer route, approval
prompts, power cycling, and clean-machine installation still need physical
qualification. This is not a completed v1 acceptance run.

## Privacy

The bridge runs locally. It does not collect telemetry, audio, transcripts, or
prompt content. Claude owns voice input when its composer microphone is
available. Claude Code views without that control use macOS Dictation.
Hook requests contain only the session ID, event name, and notification type.
Health diagnostics do not return session IDs or working directories.
Invalid hook requests return a fixed error without quoting the request body.
If a diagnostic adapter fails, the health endpoint returns a fixed error and
keeps the local server running.

## Release files

The release includes a ZIP archive, its SHA-256 checksum, and an SPDX SBOM. The
SBOM records the SHA-256 of the embedded Node.js runtime, and release
verification compares that value with the binary extracted from the ZIP.

Setup and removal update only Louder Bridge hooks in Claude's settings. If an
operation fails, rollback keeps unrelated changes made while that operation
was running.

Before source setup, `npm run doctor` checks that the Mac has the compiler and
SDK needed to build the native driver. The installed app checks its bundled
driver instead.

During logout, upgrades, and service restarts, Louder Bridge closes its local
server and releases voice input even if the Micro reports a cleanup error.
If the native dictation helper stops responding, the bridge waits for it to
exit and escalates termination before accepting another MIC gesture.

Source setup waits for permission onboarding and verifies the replacement
background agent before deleting the previous app backup. Failed activation
restores the prior installation. SIGINT and SIGTERM also cancel onboarding and
finish rollback before source setup exits.

When the hook server is down, the status command reads the installed app
version and launches a fresh app probe for Input Monitoring and Accessibility.
Onboarding uses the same probe so a newly granted permission takes effect
without reopening Louder Bridge by hand.

The release workflow accepts tags only when their commit belongs to the
protected default branch. It also audits production dependencies before
signing or packaging the app.

## Why this is still a prerelease

The device protocol, Claude session navigation, and Claude voice route are
experimental interfaces. A stable v1 release requires supported interfaces
from Work Louder and Anthropic.
